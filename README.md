# EncChat

Зашифрованный мессенджер, работающий целиком в браузере. Статический сайт для GitHub Pages — свой сервер и белый IP не нужны.

## Как это работает

- Связь через публичный MQTT-брокер по WSS (`broker.emqx.io`), брокер — это только ретранслятор.
- Ключ комнаты: `PBKDF2-SHA256` (310 000 итераций) от фразы-пароля + название комнаты.
- Сообщения: `AES-256-GCM` с случайным IV на каждое сообщение, AAD привязан к комнате (шифротекст нельзя перекинуть в другую комнату).
- Брокер и любой посредник видят только зашифрованные байты. История хранится только локально в браузере и тоже зашифрована.
- Защита от повторов/дублей: уникальный ID каждого сообщения, повторы игнорируются.
- Онлайн-статус собеседников через retained presence-сообщения с Last Will.

## Деплой на GitHub Pages

1. Создай репозиторий на GitHub (например, `encchat`) — обычный, без README.
2. Залей код:
   ```
   git init
   git add .
   git commit -m "EncChat"
   git remote add origin https://github.com/<твой-логин>/encchat.git
   git branch -M main
   git push -u origin main
   ```
3. Открой репозиторий → Settings → Pages → Source: **GitHub Actions** (workflow уже в репозитории, он сам всё задеплоит).
4. Через пару минут открой `https://<твой-логин>.github.io/encchat/`.

## Использование

1. Первый участник заходит в комнату: ник, название комнаты, фраза-пароль.
2. Название комнаты и фразу-пароль передаёт второму **другим каналом** (личка, звонок) — не внутри чата.
3. Второй входит с теми же комнатой и фразой. В шапке видно ID и ники участников онлайн — сверьте их вне чата, чтобы убедиться, что вы двое.

## Тест локально

Просто открой `index.html` в браузере (двойной клик). WebCrypto работает на `file://`, MQTT уходит через WSS.

## Замечания по безопасности

- Защита построена на секретности фразы-пароля. Если её слили — считай комнату скомпрометированной, меняй фразу и комнату.
- В модели общей фразы-пароля любой, кто знает фразу, может писать от любого ника (подписи нет).
- Публичные MQTT-брокеры — это ок для друзей; для полной приватности замени брокер на свой в поле «Дополнительно».
